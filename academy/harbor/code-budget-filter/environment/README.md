# Wonder Toys budget-filter exercise

This is an isolated coding exercise using the Wonder Toys product catalogue. Implement `filter_by_budget(products, limit)` in `budget_filter.py`. Each product is a dictionary with a numeric `price`. Return the products with `price < limit`, in their original order, without changing the input. An empty input should return an empty list.

The function is a candidate utility. This exercise does not wire it into the running shopping agent.
